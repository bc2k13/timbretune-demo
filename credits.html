Project audio

The project audio examples were selected by the site owner. The table below lists the source and reference file for each pairing. Recording credits and licenses are not specified in the project metadata; the dataset licenses below apply only to their respective datasets.

VocalSet

Julia Wilkins, Prem Seetharaman, Alison Wahl, and Bryan Pardo. VocalSet: A Singing Voice Dataset (2018). Original recordings are distributed under Creative Commons Attribution 4.0. Excerpts come from the VocalSet11.zip archive.

LibriSpeech

Vassil Panayotov, Guoguo Chen, Daniel Povey, and Sanjeev Khudanpur. LibriSpeech ASR corpus (2015), test-clean. Distributed under Creative Commons Attribution 4.0, derived from LibriVox audiobooks.

Changes made

Source and reference recordings are resampled to mono 44.1 kHz. TimbreTune’s website rendering workflow aligns and interpolates source and converted-performance log-mel spectrograms, then resynthesizes each setting with BigVGAN. The guide is an unclipped 0.95 Seed-VC conversion rendered with 100 steps, CFG 0.5, Auto F0 off, zero pitch shift, and length factor 1. This workflow differs from the plug-in’s SLERP conditioning.

Available morph settings run from 0 to 0.95. Alpha 0 is a reconstruction of the source. The Source and Reference players retain the input recordings. Playback uses scalar gain for level matching and at least 1.5 dB of true-peak headroom, exported as 24-bit WAVs. No additional edge fades, limiting, or denoising are applied.

The audio manifest records rendering settings, playback gains, and file hashes.
